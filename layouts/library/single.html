Compliance as a data engineering problem

From first run to your own plugin, start here.

Privateer is a validation framework that runs automated checks, called plugins, against your resources, then writes structured, machine-readable evidence in YAML, JSON, or SARIF. Built to operate at the Evaluation layer of the Gemara GRC engineering model.

Passed Failed NeedsReview NotApplicable NotRun Unknown

Every control in a report ends with one of these results: Passed or Failed when the check could decide, NeedsReview when a person has to look, NotApplicable when the control does not apply, NotRun when the check was skipped, and Unknown when it could not run.
